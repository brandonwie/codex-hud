# AGENTS.md

Local agent instructions for this repository come from the 3B project profile,
linked on each machine as the git-ignored `AGENTS.override.md`. This committed
file holds only the review pointer that hosted reviewers read.

## Code Review Rules

Review every pull request against [`REVIEW.md`](REVIEW.md), the single review
standard for this repository. Read it before the diff and apply all of it:
what to report and skip, the finding format and P0/P1/P2 severity, the review
areas, and the verification gates. Where it disagrees with general best
practice, `REVIEW.md` wins.
